# Proyecto-SPA-en-Js---Daniel-Arjona
Proyecto Single Page Application con Javascript.



Proyecto SPA en Js · Hito 1 de 5. Empiezas tu proyecto personal. No hace falta tener toda la maquetación terminada: en cada hito entregarás una pieza que funcione, con el HTML y el CSS que esa pieza necesite. En este primer hito dejas el proyecto preparado y la primera pieza en marcha: el menú, un listado y su detalle.
Preparación: monta tu proyecto

    Crea un repositorio para tu proyecto con index.html, css/ y js/, y separa el código en módulos: datos.js, ui.js y main.js.
    Configura ESLint en el proyecto. El código que entregues no debe dar errores.
    Crea un README.md en la raíz.

Parte 1 · Planificación (en el README)

    Backlog: la lista de funcionalidades de tu proyecto, partida en piezas pequeñas y ordenada por prioridad. Cada pieza debe poder hacerse en pocos días y probarse por separado (por ejemplo: «listado de productos», «alta de producto con validación», «filtro por categoría»).
    Mapa de pantallas: qué vistas tiene tu app y qué datos muestra cada una.

Parte 2 · Datos de ejemplo

    En datos.js, define al menos dos entidades relacionadas de tu proyecto (por ejemplo, productos y categorías), con 10 registros o más, y expórtalas.

Parte 3 · Menú, listado y detalle

    Menú de navegación implementado y funcional: todas las secciones de tu mapa de pantallas están enlazadas, aunque algunas estén todavía vacías. De momento son páginas normales; más adelante lo convertiremos en SPA.
    Listado principal generado desde JavaScript a partir de tus datos (tarjetas o tabla). No escribas los elementos a mano en el HTML.
    Detalle: al pulsar un elemento del listado se muestra su ficha completa.

Entrega

Escribe en la entrega el enlace al repositorio de tu proyecto. El commit que entregas debe llevar la etiqueta h1 y el repositorio debe tener commits de varios días, no uno solo al final. El viernes harás una demo de 2–3 minutos en clase.
